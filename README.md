Calculator for Windows

Start: double-click `run_calculator.cmd`.

This starts the Windows PowerShell GUI calculator. The launcher uses PowerShell STA mode, which is required for Windows Forms windows.

What is included:

- calculator buttons for C, Back, %, +/-, +, -, *, /
- keyboard support for numbers, operators, Enter, Backspace, and Escape
- a small history line that shows the last expression before the result

Important: keep `run_calculator.cmd` and `calculator.ps1` in the same folder. If you copy only the launcher, the calculator will not open.
